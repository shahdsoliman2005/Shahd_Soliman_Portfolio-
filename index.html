    Projects

    Three LLM and NLP projects first, then the other things I've built along the way.

    Research Literature Agent

    An LLM system that reads research papers, pulls out their key details in a structured form, and compares them side by side. It runs on Qwen2.5-7B in 4-bit, with optional LoRA fine-tuning, and retrieves passages with RAG over FAISS. It's served through FastAPI and ngrok, with a Streamlit client on top.

    1. Papers
    2. FAISS retrieval
    3. Qwen2.5-7B
    4. Structured comparison

    Qwen2.5-7B, LoRA, RAG, FAISS, FastAPI, ngrok, Streamlit

    CV Parser

    Reads a PDF resume and returns clean, structured JSON. Built with Mistral-Nemo and LangChain, with both Streamlit and HTML interfaces.

    1. PDF resume
    2. Mistral-Nemo
    3. JSON

    Mistral-Nemo, LangChain, Streamlit, HTML

    YouTube Transcript Summarizer

    Summarizes video transcripts in Arabic and English, using mT5 XLSum, with a Streamlit interface.
